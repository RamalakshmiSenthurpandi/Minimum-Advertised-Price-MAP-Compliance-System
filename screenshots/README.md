# Screenshots

This folder contains sample screenshots demonstrating the functionality and output of the **Minimum Advertised Price (MAP) Compliance System**.

## Contents

### violation.png
Displays a sample MAP violation report generated by the system. The report highlights products that violate pricing policies based on predefined business rules.

### email.png
Shows a sample seller notification document generated after identifying MAP violations. This demonstrates the automated reporting capability of the system.

## Note

All screenshots use sample or anonymized data for demonstration purposes. No confidential or client-owned information is included.
